# Installation

## Stable release

To install Ticket Service, run this command in your terminal:

```sh
uv add ticket_service
```

Or if you prefer to use `pip`:

```sh
pip install ticket_service
```

## From source

The source files for Ticket Service can be downloaded from the [Github repo](https://github.com/franckngaks/ticket_service).

You can either clone the public repository:

```sh
git clone https://github.com/franckngaks/ticket_service
```

Or download the [tarball](https://github.com/franckngaks/ticket_service/tarball/main):

```sh
curl -OJL https://github.com/franckngaks/ticket_service/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd ticket_service
uv sync
```
