# Installation

## Stable release

To install API Gateway, run this command in your terminal:

```sh
uv add api_gateway
```

Or if you prefer to use `pip`:

```sh
pip install api_gateway
```

## From source

The source files for API Gateway can be downloaded from the [Github repo](https://github.com/franckngaks/api_gateway).

You can either clone the public repository:

```sh
git clone https://github.com/franckngaks/api_gateway
```

Or download the [tarball](https://github.com/franckngaks/api_gateway/tarball/main):

```sh
curl -OJL https://github.com/franckngaks/api_gateway/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd api_gateway
uv sync
```
