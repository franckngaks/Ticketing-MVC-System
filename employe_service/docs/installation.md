# Installation

## Stable release

To install Incident Service, run this command in your terminal:

```sh
uv add identite_service
```

Or if you prefer to use `pip`:

```sh
pip install identite_service
```

## From source

The source files for Incident Service can be downloaded from the [Github repo](https://github.com/franckngaks/identite_service).

You can either clone the public repository:

```sh
git clone https://github.com/franckngaks/identite_service
```

Or download the [tarball](https://github.com/franckngaks/identite_service/tarball/main):

```sh
curl -OJL https://github.com/franckngaks/identite_service/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd identite_service
uv sync
```
